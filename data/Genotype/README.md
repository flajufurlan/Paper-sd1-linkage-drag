# MP6_8 Genotype Dataset

## Dataset Summary
- **Population:** MP6_8
- **Samples:** 324 individual genotypes
- **SNP markers:** 4,865 loci
- **Genotyping platform:** DArTseq

### Filtered_Genotype_MP6_8_clean.csv
- Rows represent individual genotypes
- Columns represent SNP markers
- The first column (`Genotype`) contains sample identifiers
- Subsequent columns contain SNP allele calls

## Data Format
- SNPs are encoded as nucleotide calls (e.g., A, T, G, C)
- Missing values may be present (`NA`)
- No additional filtering (e.g., MAF or missingness thresholds) has been applied
- Hapmap containg chromosome and position information
